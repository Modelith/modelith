# Modelith 0.1.0-alpha.8

構造の関係を図に描けるようになりました。特殊化や依存の線、多重度、接続・結び付け・割り当て、メモを SysML の記法で描き、内部ブロック図では部品の中の部品まで表示します。あわせて、最後のファイルを閉じても新しいファイルが勝手に作られないようにしました。

## 新しい機能

- 特殊化の線：`part def B :> A;`（`specializes A`）を、B から A への白抜きの三角の線で描きます。`:> A, C` のように複数書いたときは、それぞれに線を引きます
- 部分集合・再定義・参照：`:>`（`subsets`）・`:>>`（`redefines`）・`::>`（`references`）を、図に描く要素どうしのときは線で描きます。定義の中の要素では、箱の中の行（`b : B :> a`）や部品の線の端（`redefines w`）に書きます
- 多重度：`part wheels : Wheel[4];` の `[4]` を、部品として持つ線の端と箱の中の行に表示します。`ordered`・`nonunique` も添えます
- 依存の線：`dependency A to B;` と `#X dependency …` を、破線と開いた矢印で描きます。相手が見つからないときは問題一覧でお知らせします
- 接続の書き方：`connection` を付けない `connect a.p to b.q;` と、3 つ以上をつなぐ `connect (a, b, c);` を内部ブロック図に描きます。3 つ以上をつなぐときは、点から各端へ線を引きます
- 結び付け：`bind a.x = b.y;` を、内部ブロック図に「=」を添えた線で描きます
- 割り当て：`allocation`・`allocate x to y;` を読み、一般の図に «allocate» の破線で描きます
- フローの定義と名前付きのフロー：`flow def` を読み、`flow f : FD from … to …` のような名前付きのフローに `f : FD` のラベルを付けます
- 内部ブロック図の入れ子：部品の中の部品（2 段まで）を、外の部品の枠の中に描きます。部品の型の中に書いた接続や、`a.b.p` のように中の部品へ届く線も描きます
- メモ：`comment c about A, B /* … */` の本文を残し、一般の図に角を折った四角のメモと、相手への破線を描きます。メモは動かしたり、インスペクタから削除したりできます
- 値の書き方の区別：`=`・`:=`・`default` を書いたとおりに残し、箱の中に `m := 10`・`m default 10` のように表示します
- そのほかの書き方：`individual`（見出しを «individual part def» のように表示）、`rep … language "…" /* … */`（インスペクタに「別の言語での表し方」として表示）を読みます

## 改善

- ファイルが無いときの画面：最後のファイルを閉じたとき、新しいファイルを勝手に作らず、「開いているファイルはありません」と、新しいファイル・ファイルを開く・サンプルを開くボタンを表示します。すべて閉じて終えたときは、次に開いたときも同じ画面から始めます

## 不具合の修正

- 空の下書き：中身の無い無題のファイルが下書きとして残り、次に開いたときにサンプルが出ないことがありました。中身の無いファイルは下書きに残さず、以前に残った空の下書きも戻さないようにしました
- 依存の名前：`dependency A, B to C;` の `A` を、依存の名前と読み違えていました。依存する側として読むようになりました
- individual の読み違え：`individual x : X;` を型付きのパラメータと読み違えていました。出来事として読むようになりました

## 0.1.0-alpha.7 をお使いの方へ

- 部品の型の中に接続があるとき、または `a.b.p` のように中の部品へ届く線があるときは、内部ブロック図に中の部品が表示され、その線の位置が変わります。その線について保存した端の配置は引き継がれません
- 不完全な `connect a;`・`bind a;`・閉じていない `connect (…` は、構文エラーとして表示されるようになります

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
