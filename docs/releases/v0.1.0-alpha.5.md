# Modelith 0.1.0-alpha.5

モデルのフォルダを「プロジェクト」として扱えるようになり、プロジェクトにチェックルールのプラグインを追加して、モデルがチームの決まりに沿っているかを確かめられるようになりました。あわせて、画面の言葉を一般的なソフトウェアの言葉にそろえました。

## 新しい機能

- プロジェクト：フォルダを開いて「プロジェクトにする」を押すと、フォルダの一番上に設定ファイル（modelith.json）を作り、エクスプローラーにプロジェクト名を表示します。設定ファイルを Git などで共有すれば、チームの全員が同じ設定とプラグインを使えます。設定ファイルの無いフォルダは、これまでどおり使えます
- チェックルールのプラグイン：「ファイル → プラグイン…」から、チェックルールのプラグイン（フォルダ）をプロジェクトに追加できます。「要求には、それを満たす要素が必要」のようなチームの決まりに合わない要素を、テキストの下の問題一覧に、どのプラグインのどのルールかを添えて表示します。結果を押すとその行に移り、テキストを直すと消えます。プラグインの一覧で、有効・無効の切り替えと削除ができます。プロジェクトとプラグインは、フォルダを開ける Chrome と Edge で使えます。ルールの書き方は[チェックルールの書き方](https://github.com/modelith/modelith/blob/dev/docs/reference/check-rules.md)をご覧ください
- 未追加のプラグインの案内：プロジェクトで使うプラグインが追加されていないとき、またはバージョンが違うときは、エクスプローラーと問題一覧でお知らせし、そこから追加できます

## 改善

- 画面の言葉：独特な言い換えをやめ、一般的なソフトウェアの言葉にそろえました（例：「版」→「バージョン」、「誤り」→「エラー」、「モデルの入れ物」→「パッケージ」）

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
