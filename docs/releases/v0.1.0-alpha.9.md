# Modelith 0.1.0-alpha.9

振る舞いを図に描けるようになりました。アクションの流れをアクティビティ図に、状態の遷移を状態遷移図に描き、シーケンス図にはイベントと順序を描きます。あわせて、テキストの語の意味を表示する機能と、スマホで見て確かめるための画面を加えました。

## 新しい機能

- アクティビティ図：アクション定義の流れを描く図を、組み込みの図に加えました。＋メニューの「アクティビティ図」か、ツリーのアクション定義の「アクティビティ図で開く」で開きます。`first a then b;`・`then b;` の順序、`if g then b;`・`else b;` の条件、`fork`・`join`・`merge`・`decide`、`send`・`accept`・`assign`・`terminate`、`if`・`while`・`for` を SysML の記号で描きます。図の上で 2 つの要素の間に線を引くと `first a then b;` を書き、線を消すとその文を消します
- 状態遷移図：状態定義の状態と遷移を描きます。ツリーの状態定義の「状態遷移図で開く」か、`view v : StateTransitionView { expose S; }` で開きます。遷移には「きっかけ [条件] / 動作」のラベルを付け、入れ子の状態、`parallel` の並行の領域（破線で区切る）、`entry`・`do`・`exit` の区画も描きます。図の上で遷移を引く・消すこともできます
- 遷移の書き方：`transition t first a accept E if g do act then b;` のきっかけ・条件・動作と、状態の中の省略形（`accept E then b;`・`if g then b;`・`then b;`）、最初の遷移（`entry; then s;`）を読みます
- シーケンス図のイベントと順序：部品の中に書いた `event occurrence` を生存線の上に描き、`first a.e then b.r;` の順序に合わせて上から並べます。生存線をまたぐ順序は破線の矢印で描き、図から消すこともできます。順序が循環しているときや相手が見つからないときは、問題一覧でお知らせします
- 語の説明：テキストのキーワード・標準のビューの名前・よく使う標準ライブラリの名前に、その意味を表示します。マウスを乗せると吹き出しで、カーソルのある語はテキストの下の行に表示します
- スマホの画面：幅の狭い画面では、テキストを読み取り専用で開きます。書き換えるときは「編集」を押します。語をダブルタップすると、その語を選んで意味を表示します
- ビューの絞り込みの式：`filter @SysML::PartDefinition or @SysML::PortDefinition;` のように、`and`・`or`・`xor`・`not`・括弧で条件を組み合わせられます。`istype`・`hastype` も使えます
- 3 段以上の部品のつながり：`connect controller.board.relay.coil to heater.power;` のように深い部品を指す線を、内部ブロック図で中の部品まで描きます。たどれない段は問題一覧でお知らせします
- draw.io への書き出し：アクティビティ図・状態遷移図と、シーケンス図のイベントと順序も、記号のまま書き出します

## 改善

- 図の名前：図の種類を、広く知られた名前で呼ぶようにしました。「構造」は「ブロック定義図」、「シーケンス」は「シーケンス図」になります。＋メニュー・タブ・保存された図のツールチップには、当たる SysML v2 の標準のビューの名前（「SysML v2 では ActionFlowView」など）を添えます。幅の狭い画面では、＋メニューの項目の下に小さく書きます
- 図を開いたときの大きさ：アクティビティ図・状態遷移図・シーケンス図は、全体を入れるために小さくしすぎず、文字が読める大きさで開きます
- 幅の狭い画面のヘッダー：ファイル名を 1 行に収め、要素と関係の数を省略して表示します

## 不具合の修正

- 受け取るアクション：`accept e : E;` を黙って読み飛ばしていました。受け取るアクションとして読むようになりました
- 代入：`assign x := v;` を、親の要素の式として読み違えていました。代入のアクションとして読むようになりました
- 順序の後のイベント：`then event occurrence e;` を黙って読み飛ばしていました。順序の相手のイベントとして読むようになりました
- 表し方の書き方：`render rendering r :> asTreeDiagram { … }` を黙って読み飛ばしていました。ビューの表し方として読み、図の描き方に使うようになりました
- 深い部品のつながり：`a.b.c.p` のように 3 段以上の部品を指す線は、3 段目より先を捨てていました。最後の段までたどるようになりました

## 0.1.0-alpha.8 をお使いの方へ

- 「構造」と「シーケンス」のタブは、「ブロック定義図」と「シーケンス図」と表示されます
- スマホなど幅の狭い画面では、テキストが読み取り専用で開きます。書き換えるときは「編集」を押してください
- `then`（行き先）の無い `transition` は、構文エラーとして表示されるようになります
- 状態の中の省略形の遷移（`accept E then b;` など）を読むようになったため、行き先が見つからないときは問題一覧に表示されるようになります
- シーケンス図では、順序（`first … then`）を書いたメッセージの並び順が、書いた順ではなく順序に従うようになります
