# Modelith 0.2.0-alpha.2

0.2.0 の最初のプレリリースです。図の種類を選んで新しい図を作れるようにし、名前・説明・属性を画面で編集できるようにしました。要求図・ブロック定義図・内部ブロック図・アクティビティ図で、これまで描けなかった書き方も描くようにしました。

## 新しい機能

- 図の種類を選んで作成：「図」メニューの「新しい図を作成…」で、名前と図の種類（今の図のまま・一般の図・内部ブロック図・アクティビティ図・状態遷移図・シーケンス図）を選べるようにしました。一般の図（ブロック定義図・要求図）は、要素の無い空の図から始められます
- 描く対象を選ぶ：内部ブロック図・アクティビティ図・状態遷移図・シーケンス図では、描くブロック・アクション定義・状態定義・シナリオをモデルから選べます。モデルに無ければ、その場で新しく作ってその図にします
- サイドバーの「図」：サイドバーに「図」のタブを足し、作成した図を並べました。選ぶとその図が開きます。行のボタン・右クリック・F2・Delete キーで、図の名前の変更と削除ができます。名前を変えても図の配置と開いているタブは残り、削除しても図に出していた要素はモデルに残ります
- 日本語の名前：名前の変更で、日本語や空白を含む名前を付けられるようにしました（テキストには `'電気ケトル'` のように引用符付きで書きます）
- 説明と属性の編集：インスペクタで、要素の説明（要求の文章など）を書き換えられるようにしました。属性とその値も一覧し、追加・値の変更・削除ができます
- 要求図：要求の区画に、前提（`assume`）と満たすべき制約（`require`・`assert`。否定の `assert not` も）の式を書くようにしました。検証・解析の区画には目的（`objective`）を書きます。パッケージの直下の検証・解析も図に出し、型の無い検証の中の `verify` からも検証の線を引きます
- ブロック定義図：パッケージの直下のアクション・アイテム・状態も図に出すようにしました。すべての定義の区画に説明（`doc`）を書き、別の言語での表し方（`rep`）を «rep» の付いたメモで描きます
- 内部ブロック図：対象のブロックそのもののポートへの線を、図の枠の上のポート（入力は左・出力は右・双方向は下）へ引くようにしました。型の無い部品は、本体に書いたポートを描きます
- アクティビティ図：アクションのパラメータ（`in`・`out`）をアクションの縁に、アクション定義そのもののパラメータを枠の上に描き、パラメータの間の流れ（`flow`）を矢印で描くようにしました。中に流れを書いたアクションは、その中に流れを描きます

## 不具合の修正

- 入れ子の部品のポート：内部ブロック図で、部品の中の部品の接続点をポートにすると、つながっていた線の端（`a.x.i` など）の書き換えが崩れていました。部品の道のりのまま書き換えるようになりました

## 0.1.0-rc.1 をお使いの方へ

- この版は <https://modelith.github.io/modelith/preview/> で開きます。前回の続き・下書き・設定・プラグインの許可は、<https://modelith.github.io/modelith/> とは別に保存されるため、最初は空から始まります。ファイルそのものは同じものを開けます
- 「新しい図を作成…」を押すと、図の種類を選ぶ画面が出ます。これまでと同じく表示中の図をそのまま残すときは、「今の図のまま」を選んだまま「作成」を押してください

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。

- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
