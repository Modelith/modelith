# Modelith 0.2.0-alpha.1

0.2.0 の最初のプレリリースです。図の種類を選んで新しい図を作れるようにし、作成した図をサイドバーの「図」にまとめました。

## 新しい機能

- 図の種類を選んで作成：「図」メニューの「新しい図を作成…」で、名前と図の種類（今の図のまま・一般の図・内部ブロック図・アクティビティ図・状態遷移図・シーケンス図）を選べるようにしました。一般の図（ブロック定義図・要求図）は、要素の無い空の図から始められます
- 描く対象を選ぶ：内部ブロック図・アクティビティ図・状態遷移図・シーケンス図では、描くブロック・アクション定義・状態定義・シナリオをモデルから選べます。モデルに無ければ、その場で新しく作ってその図にします
- サイドバーの「図」：サイドバーに「図」のタブを足し、作成した図を並べました。選ぶとその図が開きます。行のボタン・右クリック・F2・Delete キーで、図の名前の変更と削除ができます。モデルのツリーで図の行を右クリックしても、同じことができます
- 図の名前の変更と削除：名前を変えても、図の配置と開いているタブはそのまま残ります。削除するときは確認を取り、図に出していた要素はモデルに残します

## 0.1.0-rc.1 をお使いの方へ

- 「新しい図を作成…」を押すと、図の種類を選ぶ画面が出ます。これまでと同じく表示中の図をそのまま残すときは、「今の図のまま」を選んだまま「作成」を押してください

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
