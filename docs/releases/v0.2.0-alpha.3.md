# Modelith 0.2.0-alpha.3

フォルダの中の複数のファイルを 1 つのモデルとして読み、すべてのファイルの問題を一覧できるようにしました。線の形の調整、画像でのエクスポートとコピー、知らせの重さの選択を加え、0.1.0-rc.1 をお使いの方からいただいたご意見に沿って、ファイルの開き方と図のタブを見直しました。

## 新しい機能

- 複数のファイルのモデル：フォルダを開いているときは、フォルダの中のファイルを 1 つのモデルとして読むようにしました。ほかのファイルの一番上の要素はその名前で、パッケージの中の要素は `import Parts::*;` のような取り込みか `Parts::Wheel` のような名前で使え、「見つかりません」と出なくなります。図には、ほかのファイルの要素にファイル名の札を付けて描きます。ほかのファイルの要素を選ぶと、インスペクタの「そのファイルを開く」でそのファイルへ移れます
- すべてのファイルの問題：フォルダを開いているときは、問題一覧に、表示中のファイルの問題に続けて、フォルダの中のほかのファイルの問題をファイルごとに並べるようにしました。行を押すと、そのファイルのその行へ移ります。ファイルの一覧では、エラーのあるファイルの名前を赤く、警告だけのファイルの名前を黄色くし、件数を添えます
- 線の形の調整：線を選ぶと、曲がり角と区間の中ほどにつまみを出すようにしました。中ほどのつまみを動かすと曲がり角が増え、曲がり角のつまみを動かすと曲がり角が動き、ダブルクリックすると消えます。線の端のつまみを同じ要素の別の縁へ動かすと、端を付け替えます。インスペクタの「線の形を元に戻す」で元の形に戻ります。調整した形は図の配置と一緒に保存し、エクスポートにも書きます
- 画像のエクスポート：「エクスポート…」の形式に「PNG 画像（.png）」と「JPEG 画像（.jpg）」を足し、倍率（1 倍・2 倍・3 倍）を選べるようにしました。画像の形式では、範囲（図の全体・選んだ要素）と背景（白・透明）も選べます
- 画像をコピー：「エクスポート…」の「画像をコピー」で、図を画像としてクリップボードに入れ、ほかのアプリに貼り付けられるようにしました
- 問題のコピー：問題一覧の行を右クリックするか、行を選んで Ctrl＋C を押すと、その行を「ファイル名:行: メッセージ」の形でコピーするようにしました。「すべてコピー」で一覧のすべてをコピーできます
- 知らせの重さ：「表示」メニューと問題一覧の「知らせの重さ…」で、トレースの抜け（導出・満たす要素・検証）・まだ扱えない書き方・チェックルールの結果を、種類ごとに「エラー」「警告」「情報」「出さない」から選べるようにしました。選んだ重さはプロジェクトの設定（modelith.json）に保存し、コマンドラインのチェックも従います。フォルダをプロジェクトにすると選べます
- アクティビティ図の区画：部品が受け持つアクション（部品の本体に書いた `perform`）を、部品ごとの区画（スイムレーン）に分けて描くようにしました

## 改善

- 図のタブをファイルごとに：図のタブを、ファイルごとに持つようにしました。ファイルを切り替えると、そのファイルで最後に開いていたタブに戻ります。初めて開くファイルは「すべて」の図から始まります。表示中の図にそのファイルの要素が無いときは、そのことと、ほかの図をタブの「＋」から開けることを示し、「すべて」の図を開くボタンを出します
- ファイルを仮に開く：フォルダの一覧で 1 回クリックしたファイルは仮に開き（名前は斜体）、次に 1 回クリックしたファイルと置き換わるようにしました。ファイルを次々に見ても、開いているファイルが増え続けません。ダブルクリックするか編集すると、開いたままになります
- 他のアプリでの変更の知らせ：開いた後に他のアプリで変更されたファイルを編集し始めると、ファイル名を示して、ファイルの内容を読み込むか、このまま編集するかを尋ねるようにしました。画面に戻ったときは、表示中のファイルに限らず、他のアプリで変更されたファイルの名前をまとめて知らせます

## 不具合の修正

- 画面に戻ったときの入力：入力した直後に Modelith の画面に戻ると、そのファイルが他のアプリで変更されていた場合に、ファイルを読み直して入力が消えることがありました。入力を未保存の変更として残し、読み直さないようになりました

## 0.2.0-alpha.2 をお使いの方へ

- フォルダの一覧でファイルを 1 回クリックすると、仮に開くようになりました。複数のファイルを開いたままにするときは、ダブルクリックしてください
- 図のタブはファイルごとに覚えるため、初めて開くファイルでは「すべて」の図から始まります

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
