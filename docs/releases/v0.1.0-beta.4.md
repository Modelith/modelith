# Modelith 0.1.0-beta.4

メニューを、ほかのアプリと同じく画面の左上に並べ直した版です。機能は beta.1 のまま固定しています。

## 改善

- メニューの位置：画面の右上に集まっていた「ファイル」「ヘルプ」のメニューと、元に戻す・やり直すのボタンを、左上のロゴの隣に並べ直しました。右上には、同期の状態と開発段階の札だけが残ります
- メニューの分け方：メニューを「ファイル」「編集」「表示」「図」「プラグイン」「ヘルプ」に分けました。今ある操作を、次のように集めています
  - 編集：元に戻す・やり直す・すべて選択
  - 表示：ツリーとテキストのパネル、拡大・縮小・全体を表示・全体図
  - 図：図を保存・線を曲線で描く・整列・図を SVG で保存・draw.io 形式で書き出す
  - プラグイン：プラグインの一覧と、プラグインが足したコマンド・取り込み・書き出し
- メニューの操作：メニューを 1 つ開いている間は、マウスを隣のメニューに乗せると切り替わります。キーボードでは、左右の矢印キーで隣のメニューへ、上下の矢印キーで項目を移れます
- 幅の狭い画面：メニューを左上の「☰」の 1 つにまとめました

## 0.1.0-beta.3 をお使いの方へ

- 「プラグイン…」は、「ファイル」メニューから「プラグイン」メニューの「プラグインの一覧…」に移りました
- 「図を SVG で保存」と「draw.io 形式で書き出す」は、「ファイル」メニューから「図」メニューに移りました
- 「ヘルプ」は、画面の右上から左上のメニューの並びに移りました
- ツリーとテキストのパネルの切り替えは、画面の右上のボタンから「表示」メニューに移りました

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
