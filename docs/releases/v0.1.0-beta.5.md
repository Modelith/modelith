# Modelith 0.1.0-beta.5

図のエクスポートを「ファイル」メニューにまとめ、メニューの言葉をほかのツールに合わせた版です。機能は beta.1 のまま固定しています。

## 改善

- エクスポートの画面：「ファイル」メニューの「エクスポート…」から、ファイル名と形式（SVG 画像・draw.io）を選んで、表示中の図をファイルとしてダウンロードできるようにしました。形式を切り替えると、ファイル名の拡張子も合わせて変わります
- draw.io の形式：これまでは draw.io 用の内容をコピーして貼り付けていましたが、`.drawio` のファイルとしてダウンロードし、draw.io でそのまま開けるようにしました
- 新しい図を作成：名前を付けて図をモデルに残す「図を保存…」を、ほかの SysML のツールに合わせて「新しい図を作成…」と呼ぶようにしました。図のタブの「＋」のメニューも、「自動で描く図」と「作成した図」の 2 つに分けました
- 線の形：線を直角で描くか曲線で描くかを、「表示」メニューの「線の形」で選べるようにしました。図のツールバーの「線：直角」のボタンも、これまでどおり使えます
- 言葉：画面の「書き出し」を「エクスポート」、「取り込み」を「インポート」に改め、ほかのツールと同じ呼び方にしました
- ヘッダー：ロゴの横の副題をなくし、すっきりさせました

## 0.1.0-beta.4 をお使いの方へ

- 「図を SVG で保存」と「draw.io 形式で書き出す…」は、「図」メニューから「ファイル」メニューの「エクスポート…」に移りました
- 「図を保存…」は「新しい図を作成…」に、「保存された図」は「作成した図」になりました。働きは同じです
- 「線を曲線で描く」は、「図」メニューから「表示」メニューの「線の形」に移りました
- プラグインのメニューの「取り込み」「書き出し」は、「インポート」「エクスポート」になりました

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
