# Modelith 0.1.0-rc.1

0.1.0 の正式版の候補（rc）です。0.1.0-beta.6 から、機能と画面の変更はありません。1 週間ほど使っていただき、重大な不具合が見つからなければ、この内容で 0.1.0 を出します。

## その他

- 正式版の候補：画面左上の札と「ヘルプ」に、正式版の候補（rc）であることを表示します。気になる振る舞いや不具合があれば、[GitHub Issues](https://github.com/modelith/modelith/issues/new/choose) でお知らせください

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
