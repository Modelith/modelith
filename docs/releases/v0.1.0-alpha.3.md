# Modelith 0.1.0-alpha.3

テキストを読み取る仕組みを新しくし、SysML v2 の文法に沿って読み取るようにしました。

## 主な変更

- 新しい読み取りの仕組み：テキストを、SysML v2 の文法に沿って読み取るようになりました。書き損じがあっても、その先を読み続けます。これまでと同じモデルが、同じ図になります
- 「;」の書き忘れ：「}」の直前で「;」を書き忘れた行も、問題一覧に出すようになりました
- 壊れたテキストへの強さ：入れ子がとても深いテキストなど、読み取れないものを入れても止まらず、問題一覧で知らせます
- 起動できないときの案内：読み取りに使う部品を読み込めないときは、白い画面のままにせず、読み込み直すよう案内します
- 起動直後の図：図を画面に合わせる位置を、正しい文字の幅で計算するようにしました

## 0.1.0-alpha.2 をお使いの方へ

- 保存形式は変わりません。これまでのファイルをそのまま開けます。
- これまで何も出なかった「}」の直前の「;」の書き忘れが、問題一覧に出ることがあります。表示された行に「;」を足してください。

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
