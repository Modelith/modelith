# Modelith 0.1.0-alpha.7

SysML v2 のテキストの書き方のうち、読める書き方を増やし、正しい書き方を誤ってエラーにしたり別の意味に読んだりする問題をなくしました。書き方ごとの対応状況と、まだ使えない書き方の対応予定を、README で見られるようにしました。

## 新しい機能

- ケースとアクター：`case def`・`case`（テストケースなどのケース）と `actor` を読み、ツリーに出します。`include use case` も読みます
- 視点と描き方の定義：`viewpoint def`・`viewpoint`、`rendering def`・`rendering` を読み、ツリーに出します
- 離れた場所からのメタデータ：`metadata M about A, B { … }` で、A と B にメタデータ（フェーズなど）を付けられます。付ける相手が見つからないときは、問題一覧でお知らせします
- 自分で決めたキーワード：`#Hazard def H;` のように、メタデータの定義をキーワードとして使った宣言を読みます。メタデータの定義に基になる種類（`baseType`）が書いてあれば、その種類として扱います
- そのほかの書き方：`enum` の使用（`enum e : E;`）、`event occurrence`・`timeslice`・`snapshot`、型付けの `typed by`、前に付ける `constant`・`variant`（`variation part def` を含む）を読みます
- 満たす関係の書き方：`by` の無い `satisfy R;`（書いた要素が満たす）と `assert satisfy` を、満たす関係の線にします。`not satisfy` は「満たさない」ことの記録として読み、線は引きません
- 対応状況の公開：README の「SysML v2 の対応状況」に、使える書き方・一部だけ使える書き方・まだ使えない書き方と、それぞれの対応予定のバージョンを載せました。書き方ごとの詳しい状況は[対応表](https://github.com/modelith/modelith/blob/dev/docs/reference/sysml-conformance.md)をご覧ください

## 改善

- 修飾名の探し方：`Q::A` のような修飾名を、書いた場所から外側へパッケージをたどって探すようにしました。同じファイルの `alias B for A;` も、指す先の要素として扱います
- 標準ライブラリの型名：`Positive`・`Rational`・`Iso8601DateTime` などの標準ライブラリの型で、「型が見つかりません」と出なくなりました。名前が `…Value` で終わる型を標準ライブラリの型とみなすのは、ISQ や SI などの量と単位のパッケージを import しているときだけにしました。名前の書き間違いに気づけます
- メタデータの値：`@M { k = 1 + 2; }` のような値を、式のまま残すようにしました

## 不具合の修正

- テキストの表し方：`rep … language "…" /* … */` の後に書いた宣言が消えたり、「「;」がありません」と出たりしていました。正しく読むようになりました
- 制約の式：`assert not constraint { x < 0 }` や `assume constraint { … }` で、「「;」がありません」と誤って出ていました。出なくなりました
- 検証の関係：パッケージの直下に書いた検証（`verification v : VD { objective { verify R; } }`）で、要求があるのに「見つかりません」と出ていました。型の定義から検証の線を引くようになりました
- 視点の中の関心事：`viewpoint` の中の `frame concern` で、関心事があるのに「見つかりません」と出ていました。出なくなりました
- まだ扱えない書き方の中身：まだ扱えない宣言の `{ … }` の中に書いた要素が、外側の要素の中身として図に出ていました。中身を外側に取り込まないようにしました
- 修飾名の結び先：`Q::A` が、別のパッケージにある同じ名前の `A` に誤って結び付くことがありました。正しい `A` に結び付くようになりました
- 名前と型だけの制約：`assert constraint c : CD;`・`require c : CD;` が読み捨てられていました。要求などの制約として残すようになりました

## 0.1.0-alpha.6 をお使いの方へ

- 書いた場所からたどれない修飾名（存在しないパッケージ名を含むものなど）は、これまで同じ名前の別の要素に結び付いていましたが、「見つかりません」と出るようになります
- import の無いファイルで、定義していない `…Value` の型（`MassValue` など）は「型が見つかりません」と出るようになります。量と単位の型を使うときは、`import ISQ::*;` などを書いてください
- まだ扱えない宣言の `{ … }` の中に書いた要素は、図とツリーに出なくなります

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
