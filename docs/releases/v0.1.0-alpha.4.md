# Modelith 0.1.0-alpha.4

大きなモデルでも入力や図の操作が止まりにくくなり、保存した図にモデルの入れ物（package）を枠として描けるようになりました。

## 主な変更

- モデルの入れ物を枠で描く：保存した図にモデルの入れ物（package）そのものを入れると、名前を書いた枠の中に、入れ物の中の要素を並べて描きます。入れ物の中の入れ物は、枠の中の枠になります
- 動きの軽さ：テキストの読み取りと図の操作を、画面とは別の処理で行うようにしました。大きなモデルでも、入力や図の操作が止まりにくくなりました
- 名前の変更：部品の名前を変えたとき、その部品を持つ定義の中だけを書き換えるようになりました。別の定義にある同じ名前は変わりません。文字列の中の文字も変えません
- まとめて削除：複数の要素を選んで削除したとき、ファイルの他の部分の空行は変えないようになりました。選んだ要素の中にある要素も一緒に選んでいても、正しく消えます
- 操作の直後の保存：図を操作した直後に保存しても、その操作の結果まで保存するようになりました
- 操作の取りやめ：図の操作を反映する前にテキストが書き換わったときは、その操作をやめて知らせるようになりました。古い位置を書き換えることはありません

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
