# Modelith 0.2.0-alpha.4

ファイルの一覧から、ファイルとフォルダの名前の変更・削除などができるようになりました。開いたフォルダを覚えるプロジェクトの一覧を加え、フォルダの切り替え・フォルダを閉じる・フォルダごとの削除ができるようにしました。

## 新しい機能

- ファイルの一覧のメニュー：フォルダを開いているとき、ファイルの一覧のファイルとフォルダを右クリックすると、メニューを出すようにしました。ファイルは「開く」「名前の変更」「削除…」「パスのコピー」「相対パスのコピー」、フォルダは「新しいファイル…」「新しいフォルダー…」「名前の変更」「削除…」「パスのコピー」「相対パスのコピー」です。「パスのコピー」は、開いたフォルダの名前から始まるパスを入れます
- 名前の変更：表示中のファイルの名前をもう一度クリックするか、F2 を押すか、メニューの「名前の変更」で、一覧の中で名前を書き換えられるようにしました。Enter で決め、Esc でやめます。使えない名前は理由を示します。開いているファイル（未保存の変更もそのまま）、図の配置のファイル、ファイルごとの図のタブも、合わせて新しい名前に移ります
- 削除：ファイルとフォルダを、名前と元に戻せないことを確かめてから削除できるようにしました。図の配置のファイルも一緒に削除し、開いていたファイルは閉じます
- プロジェクトの一覧：開いたフォルダを、最後に開いた順に 10 件まで覚えるようにしました。フォルダを開いていないときは、エクスプローラーに一覧を出し、押せば開き、「×」で一覧から外せます（フォルダの中身には触れません）。プロジェクトなら、プロジェクト名も出します
- フォルダの切り替えと閉じる：開いているフォルダの見出しの名前（▾）を押すと、一覧のほかのフォルダへの切り替え・ほかのフォルダを開く・フォルダを閉じるを選べるようにしました。ファイルメニューの「最近開いたフォルダ」と「フォルダを閉じる」からもできます。切り替えても閉じても、開いているファイルは開いたまま残ります
- フォルダごとの削除：見出しの名前（▾）のメニューの「このフォルダを削除…」で、開いているフォルダを中身ごと削除できるようにしました。削除の前に 2 回確かめ、2 回目はフォルダの名前を入力してもらいます

## 0.2.0-alpha.3 をお使いの方へ

- フォルダを開いていないときの「前回のフォルダ「…」を開く」は、プロジェクトの一覧の先頭の行に変わりました

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
