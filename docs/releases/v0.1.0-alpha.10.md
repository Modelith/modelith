# Modelith 0.1.0-alpha.10

正しい SysML v2 の書き方なのに、誤ったエラーや「見つかりません」が出ていた書き方を直しました。あわせて、読み飛ばしていた短い書き方（`flow a to b;` など）と、既存の要素を指す書き方（`perform x.y;` など）を読むようにしました。

## 新しい機能

- 短い流れとメッセージ：`flow a.p to b.p;`（`from` を省いた形）、`succession flow a to b;`、`message a to b;`・`message of M a to b;` を、長い形と同じ線として描きます
- 短いインタフェース：`interface x.p to y.p;`・`interface (a, b, c);`（`connect` を省いた形）を、接続と同じく内部ブロック図の線にします
- 既存の要素を指す書き方：`perform x.y;`・`exhibit s;`・`frame c;` を、既存のアクション・状態・関心事を指す要素として読みます。`perform x.y;` はアクティビティ図に描き、`frame c;` は関心事の型への «frame» の線にします
- 交差：`w : A => q.r;`・`crosses q.r` を読み、部品の線の端と区画の行に書きます

## 不具合の修正

- 本体が `true`・`false`・`not` で始まる制約：`constraint def C { true }`・`require constraint { not x }` で、誤って「「;」がありません」と表示していました。式として読むようになりました
- 本体付きの式：`a.b->collect{ in i; i*2 }` で、誤って構文エラーを表示していました。式として持つようになりました
- 宣言する形の満たす・検証する：`satisfy requirement r : R by x;`・`verify requirement r : R;` で、誤って「相手が見つかりません」と表示していました。型 R を満たす・検証する線を引くようになりました。ビューの定義の中の `satisfy vp;` も、誤って知らせなくなりました
- 定義の中の部品をつなぐ線：`part def S { part t; part e; connect t to e; }` のように型の無い部品をつなぐと、誤って「線の接続先が見つかりません」と表示していました。表示しなくなりました
- キーワードの無い特性：`x : Real;`・`z : Real = 3;` を捨てたり、制約の式と読み違えたりしていました。属性の行として表示するようになりました。型の無い `ref r;` も同じです
- 運ぶものに名前を付けた流れ：`flow of f : Fuel from … to …` で、名前 `f` を型として表示していました。型 `Fuel` を表示するようになりました
- メタデータの値：`@M { :>> x = 1; }` の値を捨て、要求の定義の区画に `{ :>> x = 1 }` と表示していました。メタデータの値として記録するようになりました
- 共役ポートの名前：`port y : Pt::'~Pt';` で、誤って「見つかりません」と表示していました。`~Pt` と同じく読むようになりました
- KerML の宣言：`classifier C { part p : X; }` のような KerML の宣言の中身が、外のパッケージの部品として図に出ていました。宣言ごと「まだ扱えない」と知らせるようになりました
- 関係の本体の説明：`dependency A to B { doc /* … */ }` の説明を、外のパッケージの説明として表示していました。表示しなくなりました

## 0.1.0-alpha.9 をお使いの方へ

- キーワードの無い特性（`x : Real;`）を読むようになったため、その型が別のファイル（標準ライブラリを含む）にあるときは、ほかの書き方と同じく「型が見つかりません」と表示されるようになります（ファイルをまたぐ名前の解決は 0.2.0 で行います）
- KerML の宣言（`classifier`・`function` など）は、問題一覧に「まだ扱えない」と表示されるようになります

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
