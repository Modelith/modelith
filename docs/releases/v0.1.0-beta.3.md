# Modelith 0.1.0-beta.3

画面の言葉とキーボードでの操作を整えた版です。ブラウザの英語のエラー文を日本語にし、ダイアログ・図のタブ・ツリー・メニューをキーボードで操作できるようにしました。機能は beta.1 のまま固定しています。

## 改善

- エラーの文：保存や読み込みに失敗したとき、ブラウザの英語の文（「The request is not allowed by the user agent…」など）をそのまま出していました。「フォルダやファイルを編集する許可がありません。もう一度開いて、ブラウザの確認で許可してください」のように、何が起きたかと次の操作を日本語で示します
- ダイアログ：開いている間は、Tab キーで後ろの画面へ移らなくなりました。閉じると、開く前に操作していたボタンへ戻ります
- 図のタブ：Tab キーで図のタブに移り、左右の矢印キー・Home・End で図を切り替えられます
- モデルのツリー：Tab キーでツリーに入り、上下の矢印キーで要素を選べます
- メニュー：「ファイル」「ヘルプ」と図の「＋」のメニュー、draw.io 形式の書き出しの画面を、Esc キーで閉じられます
- 起動中の表示：開いてから使えるようになるまで「読み込み中…」と表示します。15 秒たっても使えないときは、再読み込みを案内します

## その他

- セキュリティの問題の報告先：利用者のモデルが外部に送られる、プラグインの隔離を抜けられるといった問題は、公開の Issue ではなく、[非公開の報告](https://github.com/modelith/modelith/security/advisories/new)でお知らせください

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
