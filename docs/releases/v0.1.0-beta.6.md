# Modelith 0.1.0-beta.6

トレースの抜けを、図を見たまま見つけて直せるようにした版です。機能は beta.1 のまま固定しています。

## 改善

- トレースの抜けの案内：図のサブバーの「トレースの抜け N 件」を押すと、図を見ているときは図のまま、抜けのある要求を選んで図の中央に出すようにしました。下の欄に、何が足りないか（「この要求を確かめる検証がありません」など）と直し方を示し、その場で「関係を追加」を押して直せます。テキストで確かめたいときは「テキストで見る」を押します
- 抜けが複数あるとき：案内の欄の「1 / 3 件目」と「‹」「›」で、次の抜けへ順に移れるようにしました
- 図の上の印：抜けのある要素の箱に △ の印を付け、マウスを乗せると何が足りないかを示すようにしました
- 問題一覧：「△」の行を押したときも、図が見えていれば図の要素へ移るようにしました。スマホでテキストのタブを見ているときは、これまでどおりテキストの行へ移ります

## 不具合の修正

- 要求をつなぐ関係：要求から検証や部品へ線を引くと、「〜として持つ」しか選べず、確かめる・満たすの関係を足せませんでした。どちらの要素から線を引いても、「この検証で確かめる «verify»」「この部品で満たす «satisfy»」「この要求へ展開する «derive»」「この要求で扱う «frame»」を選べるようになりました
- トレースの抜けの文：短い名前（`<'K3'>` など）の無い要求で、「FlowReq FlowReq：…」のように名前が 2 回出ていました。名前を 1 回だけ出すようになりました

## 0.1.0-beta.5 をお使いの方へ

- 「トレースの抜け N 件」を押しても、テキストの画面には切り替わらず、図のまま案内します。テキストで見るときは、案内の欄の「テキストで見る」を押してください

## ご注意

- 開発中の版のため、操作方法や保存形式は予告なく変わることがあります。
- 本ソフトウェアは無保証です。
- フォルダを開いてファイルを直接保存できるのは、Chrome と Edge です。
- 保存先のないファイル（新規作成したファイルやサンプル）は、ブラウザ内に下書きとして一時的に残るだけです。必要なものは「名前を付けて保存」で保存してください。
