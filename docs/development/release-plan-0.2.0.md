# リリース計画（0.2.0）

`0.1.0` の次のマイルストーン `0.2.0` の進め方。進め方は [0.1.0 の計画](release-plan.md) と同じく alpha → beta → rc の順にプレリリースを出し、
始めてから **1 週間を目処に `0.2.0-rc.1`** を出す（メンテナの判断、2026-10-22）。バージョンの付け方は [バージョン規則](../reference/versioning.md)、手順は [リリース手順](releasing.md)。

## 目標

「図だけでも、テキストだけでも、両方を行き来しても使える」を、図だけで使う人にとっても確かなものにする。
0.1.0 の beta の間に分かった「画面ではまだできないこと」と、0.1.0 の後に回した図の操作を入れる。

## 進め方

| 段階 | 版 | 内容 |
| --- | --- | --- |
| alpha | `0.2.0-alpha.N` | 下の「入れるもの」を 1 つずつ入れ、入れるたびに alpha を出す。要求を先に更新し、テストを `verify` で結ぶ |
| beta | `0.2.0-beta.N` | 機能を固定し、不具合の修正だけを行う |
| rc | `0.2.0-rc.1` | 始めてから 1 週間を目処に出す。`dev` → `main` のマージはメンテナの許可を取る。目安 1 週間、重大な報告が無ければ `0.2.0` |

1 週間に収まらないものは、alpha の途中でメンテナと相談して 0.3.0 に回す。

## 入れるもの（alpha の順）

| 順 | 版 | 内容 | 要求 |
| --- | --- | --- | --- |
| 1 | `0.2.0-alpha.1` | 図を作る：「新しい図を作成…」で名前と図の種類を選び、空の図からも作れる。サイドバーに作成した図を並べ、開く・名前の変更・削除ができる | F-VIEW-8 ほか |
| 2 | `0.2.0-alpha.2` | 画面で編集できることを増やす：要求の文章、属性とその値、日本語の名前（SysML v2 の `'…'` の名前）を、テキストを書かずに編集できる | F-EDIT-2 ほか |
| 3 | `0.2.0-alpha.3` | エクスポートの強化：PNG・JPEG・範囲（図の全体・選んだ要素）・倍率・背景、画像のコピーを、ファイルメニューの「エクスポート…」の画面に足す | F-EXP-1・F-EXP-2 ほか |
| 4 | `0.2.0-alpha.4` | 知らせの重さを選べる：トレースの抜け・まだ扱えない構文・チェックルールの結果を、種類ごとに「エラー」「警告」「情報」「出さない」から選ぶ | F-EDIT-11 |
| 5 | `0.2.0-alpha.5` | プロジェクトの一覧：開いたプロジェクトの一覧・切り替え・一覧から外す・フォルダを閉じる | F-PROJ ほか |

## 相談して決めるもの

| 項目 | 内容 | 判断 |
| --- | --- | --- |
| 複数のファイルにまたがるモデル | `import`・別のファイルの `alias`・修飾名・可視性（[SysML v2 の文法への対応](release-plan.md#sysml-v2-の文法への対応) の 0.2.0 の行、ADR-0019） | 仕組みが大きく 1 週間に収まりにくい。alpha の途中で進み具合を見て、0.2.0 に入れるか 0.3.0 に回すかを決める |
| フォルダごと削除 | プロジェクトのフォルダを、確認を 2 回取ってから削除する | 取り消せない操作なので、要求と画面をメンテナと決めてから入れる |
