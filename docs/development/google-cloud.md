# Google Cloud の準備（Google ドライブ連携）

Google ドライブとの連携（ADR-0012）に必要な、Google Cloud 側の設定。メンテナが一度だけ行う。

> ADR-0012 は保留中。連携に着手するまで、この設定は不要。
ここで作る値（クライアント ID・API キー）はページに埋め込む公開の値で、秘密ではない。悪用は、下の制限で防ぐ。

## 1. プロジェクトと API

1. Google Cloud コンソールでプロジェクトを作る（例: `modelith`）。
2. 「API とサービス」→「ライブラリ」で、次の 2 つを有効にする。
   - Google Drive API
   - Google Picker API

## 2. OAuth 同意画面

| 項目 | 設定 |
| --- | --- |
| ユーザーの種類 | 外部 |
| アプリ名 | Modelith |
| スコープ | `https://www.googleapis.com/auth/drive.file` だけ |
| 公開ステータス | 最初は「テスト」。試す人をテストユーザーに登録する（100 人まで） |

一般公開（「本番環境」）にするときは、プライバシーポリシーとホームページの URL が必要になる。
アプリ名やロゴを同意画面に出すには、Google のブランド確認を受ける。`drive.file` は審査の軽い権限なので、スコープの審査は不要の見込み。

## 3. OAuth クライアント ID

「認証情報」→「認証情報を作成」→「OAuth クライアント ID」。

| 項目 | 設定 |
| --- | --- |
| アプリケーションの種類 | ウェブ アプリケーション |
| 承認済みの JavaScript 生成元 | `https://modelith.github.io`（パスと末尾の `/` は付けない） |
| 〃（開発用） | `http://localhost:5173` |
| 承認済みのリダイレクト URI | 空のまま（トークン方式のポップアップでは使わない） |

## 4. API キー（Google Picker 用）

「認証情報」→「認証情報を作成」→「API キー」。作ったら、すぐに次の制限をかける。

| 項目 | 設定 |
| --- | --- |
| アプリケーションの制限 | ウェブサイト：`https://modelith.github.io/*`、`http://localhost:5173/*` |
| API の制限 | Google Picker API だけ |

## 5. 値の受け渡し

クライアント ID と API キーは、ビルド時の設定として Web アプリに埋め込む（入れ方は実装の PR で決める）。
値を変えたとき・漏れて悪用されたときは、Google Cloud 側で作り直し、新しい値でリリースする。
