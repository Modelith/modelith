# ADR-0009: モックのコードを移植して最初の alpha を公開する

- 状態: 採用（2026-10-20：暫定コアを `0.1.0-beta.1` で削除した）
- 日付: 2026-10-12

## 背景

テストユーザーになってくれる利用者がいて、早く触ってもらいたい。
ADR-0002 の順序（Rust コアを作ってから UI を移植する）では、最初の alpha が数週間遅れる。
一方、Web アプリとして公開する以上、配信する JS は誰でも読めるため、
「モックのコードを非公開に保つ」ことと「モックの機能を早く公開する」ことは両立しない。

## 決定

- モックの UI とコア（パーサ・モデル構築・テキスト操作）のコードを TypeScript に移植し、`web/` に置いて AGPL で公開する。
  ADR-0002 の「モックは非公開」は、この範囲で改める。
- 引き続き非公開とするもの:
  - モックの HTML ファイルそのもの（`reference/mock/`。コミットしない。ゴールデン生成の基準として手元に置く）
  - モック内蔵のサンプルモデル。アプリには新しく作った公開サンプルを入れる
- 移植したコアは**暫定**とし、`web/src/core/` に閉じ込めて UI からはインタフェース経由でのみ呼ぶ。
  Rust コア（Worker 内 wasm、ADR-0003）がゴールデンと一致したら差し替えて削除する（目標: `0.1.0-beta.1`）。
- 暫定コアもゴールデン（`reference/golden/*.json`）との一致をテストし、移植の正しさを確かめる。

## 結果

- 最初の alpha を 1 スプリントで公開できる。
- 暫定コアの間は ADR-0003（コアは Worker 内 wasm）を満たさない。beta までに解消する。
- コアが TS と Rust の二重持ちになる期間がある。どちらもゴールデンで検証するため、仕様のずれは検出できる。
- （2026-10-20 追記）`0.1.0-beta.1` で暫定コア（`parser.ts`・`model.ts`・`text-ops.ts` など）を削除した。コアは Worker 内の Rust（wasm）だけになり、ADR-0003 を満たす。ゴールデンとの一致は Rust のコアで確かめ続ける。
