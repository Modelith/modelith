# ADR-0003: ウェブアプリを本体とし、コアは Worker 内 wasm で動かす

- 状態: 採用
- 日付: 2026-10-07

## 背景

当初 VS Code 拡張として作ったが、図の編集との相性が悪く、専用のウェブアプリを本体とすることにした。
一方で、VS Code の「拡張の受け皿」と「LSP」の設計は優れており、取り入れたい。

## 決定

- 本体はウェブアプリ（`web/`、TypeScript + Vite）。テキストエディタ部品は CodeMirror 6 を第一候補とする。
- コアは Web Worker 内の wasm（`modelith-wasm`）で動かし、UI とのメッセージは LSP と同じ形
  （診断・テキスト編集・シンボル・コードアクション等）にそろえる。
- LSP サーバ（`modelith-lsp`）は上記メッセージ層の薄いラッパーとして後から提供する。VS Code 拡張は最下位の優先度とする。
- プラグインの受け皿（拡張ホスト）は自前で作る（ADR-0004）。

## 結果

- 重い解析で UI が固まらない。
- LSP をほぼ追加コストなしで提供できる。
