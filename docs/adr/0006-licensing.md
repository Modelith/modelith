# ADR-0006: ライセンス：AGPL＋プラグイン例外＋CLA

- 状態: 採用（例外条項・CLA 本文は法務確認待ち）
- 日付: 2026-10-07

## 背景

本体はソース開示を求めるため AGPL-3.0 とする。一方、エコシステムには非公開プラグインも参加させたく、
有料の `plugins-pro` も存在する。WASM や Worker 越しに読み込むプラグインが AGPL の派生物にあたるかは曖昧である。

## 決定

1. 本体は **AGPL-3.0-only** のまま。
2. AGPL 第 7 条の追加許可として **プラグイン例外**（[PLUGIN-EXCEPTION.md](../../PLUGIN-EXCEPTION.md)）を付ける。
   plugin-sdk が定義するインタフェースだけを通じて本体とやり取りするプラグインには、AGPL の義務を及ぼさない。
3. 外部からの貢献は **CLA** で受ける。著作権者が本体を別ライセンスでも提供できるようにし、
   `plugins-pro` やその他の商用提供で外部貢献を含むコアを利用できる余地を残す。
4. それでも設計上は、`plugins-pro` を含むプラグインは本体のコードを組み込まず、
   プラグイン API またはプロセス境界越しにだけ接続する。
5. 契約（plugin-sdk）・ひな形・公式無料プラグインは MIT。

## 未決・要対応

- [ ] 例外条項の文言を法務確認する
- [ ] CLA 本文を用意し、CLA Assistant（GitHub App または Action）で PR ごとに署名を確認する
- [ ] 同梱する SysML v2 標準ライブラリ（OMG 由来）のライセンスとの整合を確認する
