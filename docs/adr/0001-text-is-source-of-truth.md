# ADR-0001: テキストが唯一の正本

- 状態: 採用
- 日付: 2026-10-07

## 背景

SysML v2 はテキスト記法を持つ。モック（非公開。ADR-0002）は図の操作をすべてテキストへの
書き換え（`insertInto` / `removeRange`）として実装しており、図とテキストの不整合が原理的に起きない。

## 決定

- モデルの意味内容は SysML v2 / KerML テキストだけに保存する。
- 図・プラグイン・LSP・MCP を含むすべての変更は **テキスト編集（`TextEdit` のリスト）** として表現し、
  コアが検証してから適用する。
- 位置は LSP と同じ形（0 始まりの行・列、列は UTF-16 コード単位）で外部とやり取りする。

## 結果

- Git の差分・レビュー・マージがそのままモデルの変更管理になる。
- 書式やコメントを保ったまま書き換えるため、パーサは位置情報を完全に保持する構文木（CST）が必要になる（ADR-0002）。
